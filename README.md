# violet-glitch

Dark violet theme mod for Claude Code: an ASCII night city under a slowly turning ringed planet, braille star dust, twinkling stars and windows.

## Install

```
/plugin marketplace add insanowsky/violet-glitch
/plugin install violet-glitch@violet-glitch-local
```

Or add to `~/.claude/settings.json`:

```json
"extraKnownMarketplaces": {
  "violet-glitch-local": { "source": { "source": "github", "repo": "insanowsky/violet-glitch" } }
},
"enabledPlugins": { "violet-glitch@violet-glitch-local": true }
```

Restart Claude afterwards.
